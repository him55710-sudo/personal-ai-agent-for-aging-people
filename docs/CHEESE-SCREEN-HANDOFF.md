# Cheese Windows 실행 안내

2026-11-09, Asia/Seoul

## 실행

- 저장소 루트의 `Start-Cheese.cmd`를 더블클릭한다.
- 또는 PowerShell에서 `& '.\Start-Cheese.ps1'`을 실행한다.
- Node.js 22.13 이상이 필요하다. 설치된 Node.js를 우선 사용한다.
- 기본 주소: http://127.0.0.1:4173
- 다른 포트는 `-Port 4174`, 브라우저 없이 시작하려면 `-NoBrowser`를 붙인다.
- 기존 Cheese 서버가 있으면 재사용한다. 다른 프로그램이 쓰는 포트는 오류로 안내하며 그 프로세스를 종료하지 않는다.
- 시작 오류의 로그는 `fa-kakao-demo/.data/cheese-포트.stderr.log`에서 확인한다.

## 변경 범위

GitHub `main`의 `fa-kakao-demo` 화면을 그대로 실행하는 Windows 진입점만 추가한다. 최신 main의 단일 Cheese 화면 구조와 원본 캐릭터, 서버, 라우터, 소유자 API, Android 실행, 보안 모듈은 유지한다. 개인 데이터나 환경 파일을 초기화하거나 옮기지 않는다.

기본 Cheese 화면은 원본과 같은 샘플 응답 데모다. 소유자 인증과 실제 Android 실행 서버는 `molla-app/README.md`의 별도 실행 경로를 유지한다. 실제 모델이나 VM을 자동으로 연결하지 않는다.

로컬에 있던 이전 모바일 앱과 실행기는 별도 보관본에 남겨 두었다. 최신 main에서 정리된 모바일 제품 화면을 다시 추가하지 않는다.

## 검증

- 원본 기준 `893f900`의 데모 34개, 엔진 43개, 보안 코어 65개 테스트가 모두 통과했다. `docs/testing/TEST_SPEC.md`의 대상·금액 라우팅과 승인·차단 검증을 포함한다.
- Edge에서 치즈 초대, 엄마 계정 연결의 역할 제한, 구독 보기 허용, 아들의 해지 요청, 엄마만 가능한 승인, 완료 결과와 치즈 보안 패널을 확인했다.
- 1440×960, 375×812, 812×375 화면을 확인했고 휴대폰 크기에서 가로 넘침이 없었다.
- PowerShell 7과 Windows PowerShell 5.1에서 실행과 서버 재사용을 확인했다. 임시 서버가 점유한 포트에서는 실행을 거절하고 기존 서버를 유지했다.
- 최신 main `a35ec1a`에서도 데모 테스트 34개가 모두 통과했다. Windows 실행기의 기존 서버 재사용과 별도 포트 시작을 확인했다. 서버와 화면 코드를 되돌리는 변경은 포함하지 않는다.
