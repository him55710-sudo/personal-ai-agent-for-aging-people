# Molla 촬영용 데모

> 이전 촬영용 화면의 기록이다. 독립 촬영 서버와 실행 스크립트는 제거했다. 현재 영상 시연은 [카카오톡형 치즈](../../fa-kakao-demo/README.md)를 사용한다.

외부 API·유료 Android VM 없이 동작하는 별도 촬영 모드이다. 제품의 실제 연결 상태는 `STATUS.md`를 참고한다.

## 당시 검증 흐름

촬영 화면은 합성 가족 데이터로 문자 작성, 설정 앱 열기, 가족별 대화 격리를 재현했다. 가상 Android 화면은 승인 흐름을 설명하기 위한 것이다.

## 검증 범위

- 당시 서버 로직 테스트 55개에서 기억·권한·승인과 모델·VM 어댑터를 검사했다.
- 모바일 TypeScript 검사, Expo Web export와 촬영 브라우저 흐름을 확인했다.
- 촬영은 실제 모델 호출, Phone Harness VM 생성, SMS 전송 없이 진행했다.
